# Feature: Folders

Status: **F1–F9, F11–F13, F15–F37 built** (F30–F33 since beta 14, F34 since patch 0063, F35 and F36 since 2026-10-15; F37, and the changes of 2026-10-18 to F4, F7 and F36, not yet tried on a real build, F4 not yet with VoiceOver or Narrator; F17's restart cases tested since 2026-10-18); **F10 withdrawn** (cut in patch 0055).
Owner docs: `docs/decisions/0013-folders-are-a-collection-type.md` (model). Patches: `0008` (the whole feature), `0037` (F12), `0060` (F30–F33), `0062` (F19), `0063` (F19's order, F34), and the defect round of 2026-10-18 (F37, and the changes to F4, F7 and F36).

A folder is a named, collapsible container of tabs in the sidebar. Folders nest. A folder is
a collection type in the tab tree, not a tab group, so Chrome's groups keep working and a
folder's membership cannot be overwritten by an outer group (ADR 0013).
