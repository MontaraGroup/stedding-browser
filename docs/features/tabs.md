# Feature: Tab rows

Status: **R1–R8, R10–R18, R20, R21, R23–R30 built** (R25–R30 since beta 14); **R19 partial** (a split's panes take a number each, BACKLOG S-102); **R22 partial** (the bar's Move Tab row ignores the selection, BACKLOG S-127).
Owner docs: `docs/UI-SPEC.md`. Patches: 0017, 0019, 0060.

The rows of the sidebar follow Arc: the close glyph appears only while the pointer is
on the row or its close button has keyboard focus (Arc's active row carries none), the title never re-elides when the
glyph appears, and an essentials card that plays audio keeps its favicon.

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt
(Alt+1–9 for the Spaces themselves); the full map is `docs/features/windows.md` N7.
