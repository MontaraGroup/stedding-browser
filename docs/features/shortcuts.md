chrome://settings/stedding carries a "Shortcuts" block. Every command a chord of the
shipped tables reaches has a row there, and the user can change its chords: add one,
take one off, turn the command's keys off, put its defaults back. Below the rows, the
block keeps the reference of the shipped binary: every Chromium chord Stedding rebinds
(Z2) and the platform's notes (Z3), read from the accelerator tables at startup so the
list cannot drift from the binary. Items that remap a chord add their divergence row
here, in their own patch; nothing is hand-typed.

The user's chords are one overlay over the shipped tables, applied where the tables are
read: the views accelerator table on Windows and Linux, and on the Mac the menu's key
equivalents and the table of chords coded by key. Everything that names a chord (the
menus, the command bar, the toolbar's tooltips) reads through the same lookups, so it
names the user's chord.

## Notes

- ⇧⌘D shows or hides the address row on its own (toolbar T10); Chromium had no
  chord on it in Stedding's tables, and Bookmark All Tabs keeps its menu item.
- Inside a little window (little E2, E7), ⌘O sends the page into a tab (Open File
  elsewhere; the File menu's row reads "Open in Stedding" there), ⇧⌘O into a split
  ("Open in Split View" under it) and Escape closes the window; ⌃⌘N is the split
  (welcome W6), and Chromium's ⌥⌘N splits too, where Arc opens a little window: a
  divergence recorded here, the decision left for later (little E5).
- The sideways wheel that steps through the Spaces (spaces B39: a tilt wheel or
  Shift with the wheel, on Windows also a touchpad's two-finger sideways scroll and
  Ctrl with the wheel) is not a key, so the Shortcuts block, built from the
  accelerator tables, does not list it; `docs/SHORTCUTS.md` does.
- What changing a shortcut does not reach yet: the welcome flow's steps and a few
  Settings rows name the shipped chords in their text (welcome W6, settings T13), and
  Chromium's own windows that print a chord once when they open (the profile picker, a
  presentation window) show the chord they read then.

## Decisions

- The chords live in Local State, so they are the machine's: the Mac's menu bar and
  the accelerator tables are one per app, and a chord set per profile could not be kept
  consistent there. A profile used by two people shares one set of shortcuts.
- Rows are keyed by stable names, written in the catalog. Stedding's command numbers
  are fixed constants, but the names are what installed copies keep, so a name, once
  shipped, is a compatibility promise: add rows, never rename one
  (`ShortcutCatalogTest.NamesAreStable`).
- A user chord beats a default, including a default a later release adds (Z20).
- These three are hard to reverse and want an ADR (the next free number); until it is
  written this section is the record.
