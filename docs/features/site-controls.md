# Feature: Site controls

Status: **Si1–Si11 partial**: written 2026-10-25 (BACKLOG S-118), with their tests, and released
in 0.3.0 beta 16; Si11's tests pass on the Mac (2026-10-26); not yet seen live. **Si12
planned**: its check is the acceptance script's, not yet run.
Owner docs: `docs/PRODUCT.md` §12 (Site Control Center), `docs/features/toolbar.md` T47.
Patch: 0096.

One panel for the site you are on. It is Chromium's page info, the panel the site chip at
the address row's left opens (toolbar T5), with Stedding's controls in it: a strip under
the title with Copy link, Copy title, Mute tab, Picture in picture and the page's zoom;
Chromium's security row, its permissions, with the camera and the microphone always
listed on a page that may use them, and its cookies row; Chromium's Extensions row, which
opens the extensions menu with each extension's pin; and Stedding's rows before "Site
settings": the session the page lives in, Clear site data, and the dark pages switches.
The command bar's View Site Information opens the same panel (commandbar K33), from inside
the page while the address row is hidden (toolbar T40). There is no second panel, no new
button, no setting and no new chord: each control runs the window's own command or
function, so it does what its key does.

The blocker's switch is S-88's: it will join the rows before "Site settings" when that
item is built.

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt; the
full map is `docs/features/windows.md` N7.

## Privacy

Nothing here goes to the network. The strip copies to this computer's clipboard and
changes the page's zoom; Clear site data deletes data on this computer, from one jar; the
rows read the profile's own settings. Page info records Chromium's usage metrics as it
does without Stedding, and nothing new is recorded; with metrics reporting off, as it is
by default (`docs/PRIVACY.md`), none of it leaves the computer.

## Where the code is

- The rules: `chrome/browser/ui/stedding/site_controls.{h,cc}`.
- The views: `chrome/browser/ui/views/page_info/stedding_site_controls_view.{h,cc}`, added
  to `PageInfoMainView` for the panels `PageInfoBubbleSpecification::Builder::ShowSteddingSiteControls`
  asks for (the site chip, `LocationBarView::ShowPageInfoDialog`; View Site Information,
  `ShowPageInfoDialogImpl` with the location-bar anchor and no permission page).
- Clear site data: `ClearSiteDataAndReload` in `chrome/browser/ui/stedding/site_cookies.cc`;
  Copy title: `CopyTitle` in `copy_link.cc`; the extensions menu: `ShowExtensionsMenu` in
  `chrome/browser/ui/views/commandbar/address_row_controls.cc`.

## Running the tests

```bash
tooling/dev test site-controls    # the unit tests
tooling/dev test browser 'SiteControlsTest.*:SpaceJarTest.ClearingASitesDataStaysInThatJar:IsolationMarkTest.TheSiteControlsNameTheJar:HiddenRowControlsTest.TheSiteControlsExtensionsRowOpensInsideThePage'
```

`tooling/dev test site-controls` runs the unit filter only. `SiteControlsTest.*` shows a
bubble that must keep its activation and reads the clipboard, so it runs in the browser
leg's serial part, as `HiddenRowControlsTest.*` does.
