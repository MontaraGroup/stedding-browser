# Feature: Toolbar and page bar

Status: **T1–T8, T10, T12, T14–T32, T34, T35 built** (T34, T35 since beta 14; T19–T21, T23, T25, T27 and T30 with their tests on 2026-10-18); **T11, T33 partial**: built before, each with a part written 2026-10-18 whose tests have not yet run (T11: the one rule local tabs share; T33: a bar removed without its slide, BACKLOG S-227); **T36, T37 partial**: written 2026-10-18, tests not yet run (T36 not yet tried on the real window, BACKLOG S-231; T37 with dark pages, not yet seen live); **T13, T39, T40 built** (BACKLOG S-104, 2026-10-20, on the Mac; not yet seen on the real window, and the chord not yet pressed on a real keyboard); **T41 built** (2026-10-20, a split's row in each pane's colour, on the Mac; not yet seen by the owner, full screen and a private window without a test); **T42–T44 built** (2026-10-20, on the Mac; T42's AI Mode chip itself not seen live, T43's fault not reproduced); **T9 withdrawn**.
Owner docs: `docs/UI-SPEC.md`. Patches: `0002` (layout), `0007` (colours), `0037` (T15–T18), `0060` (T34, T35), `0063` (T33's restore bar), and the S-104 patch (T13, T39, T40).

The address row is the top of the page card, not a strip above it: no gap, no hairline,
the same gutter as the card on its three free sides (6 DIP, the `card_gutter` parameter), and the page's own colour when the page declares
one. Arc's window reads the same way.

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt
(Alt+1–9 for the Spaces themselves); the full map is `docs/features/windows.md` N7.
