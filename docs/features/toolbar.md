# Feature: Toolbar and page bar

Status: **T1–T8, T10–T12, T14–T18, T22, T24, T26, T28, T29, T31–T35 built** (T34, T35 since beta 14); **T19–T21, T23, T25, T30 partial** (no unit test yet, BACKLOG S-128); **T27 partial** (no test, BACKLOG S-129); **T13 planned** (BACKLOG S-104); **T9 withdrawn**.
Owner docs: `docs/UI-SPEC.md`. Patches: `0002` (layout), `0007` (colours), `0037` (T15–T18), `0060` (T34, T35), `0063` (T33's restore bar).

The address row is the top of the page card, not a strip above it: no gap, no hairline,
the same gutter as the card on its three free sides (6 DIP, the `card_gutter` parameter), and the page's own colour when the page declares
one. Arc's window reads the same way.

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt
(Alt+1–9 for the Spaces themselves); the full map is `docs/features/windows.md` N7.
