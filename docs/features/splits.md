# Feature: Splits

Status: **J1, J4, J6–J16 built; J2 partial**; **J3, J5 planned** (all three open in BACKLOG S-102). J10–J15 (a split made by dropping a tab on the page, BACKLOG S-113, asked for in GitHub issue 7) since 2026-10-20, not yet tried on a real window. J16 (a split drawn as two pages, on the row and in the horizontal strip) since 2026-10-20, on the Mac.
Owner docs: `docs/PRODUCT.md` §4. Patch: none of its own; each row lands with the item that implements it.

A split is one row and one unit for every sidebar verb; the model is Chromium's
split view.
