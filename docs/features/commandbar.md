# Feature: Command bar

Status: **K1–K11, K13–K15, K17–K29 built** (K23–K28, K17's 7 days and K1's middle click since beta 14, K29 in patch 0068); **K12 partial** (the address-row click, BACKLOG S-127); **K16 partial** (its peek case waits on Peek, BACKLOG S-93).
Owner docs: `docs/PRODUCT.md` ("Command bar"). Patches: `0005`; `0022` (actions mode); `0060` (K23–K26); `0061` (K27, K28).

⌘T opens a bar over the page. It lists open tabs from every Space, then the omnibox's own
suggestions; typing a URL opens it, anything else searches with the default engine.

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt
(Alt+1–9 for the Spaces themselves); the full map is `docs/features/windows.md` N7.

## Notes

- The field claims ⇥ and ⇧⇥ in `SkipDefaultKeyEventProcessing`, as the omnibox does:
  on the Mac the focus manager sees a key before the focused view, and a plain
  Textfield never receives ⇥ (`docs/HANDOFF.md` trap 20).
- The panel takes the height of its rows on every rebuild, up to the 320 DIP clip
  (`CommandBarViewTest.PanelGrowsWithTheRows`).
