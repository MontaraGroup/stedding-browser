# Feature: Local tabs

Status: **Lt1–Lt14 built** (patch 0072). The live checks in `docs/features/acceptance.md` ("Local tabs") have no recorded run.
Owner: `docs/PRODUCT.md` §12, `docs/features/toolbar.md` T11, `docs/features/settings.md` T19.

A tab whose page is this machine's own web server is marked in the sidebar. The active local row wears a yellow and black dashed tape. At the Comfortable density every local row with a title of its own also shows its host and port under the title. "Local" is the address row's rule (toolbar T11): `http` or `https` on `localhost`, a name under `.localhost`, `127.0.0.0/8` or `[::1]`. One setting, on by default. No chord, and the same rules on both platforms: which rows show two lines follows the density, not the font.

## Notes

- The tape colours are fixed (`kLocalTapeYellow`, `kLocalTapeDark`), so a custom theme cannot restyle them.
- Contrast (Lt4, Lt5) is against the bare ground and the active row's fill, with the window active. In a window that is not active, Chromium dims every row's text, and the host line with it.
- The per-site switch, the developer toolbar and a JSON formatter are not here. They stay with BACKLOG S-117.
