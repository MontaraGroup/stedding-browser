# Feature: Little window

Status: **E3–E5, E7–E9 built; E1, E2, E6 partial** (E1's Pin, BACKLOG S-93; E2's Escape on the Mac, docs/history/plan-2026-09-26.md CMD-15; E6's policy path, BACKLOG S-129). The Mac, and Windows since 0.3.0 beta 7 (E10); E8's title bar is the Mac's.
Owner docs: `docs/PRODUCT.md` §5. Patch: 0035.

A link from another application opens small: a popup-type window with no sidebar,
the way Little Arc does. On the Mac since the start; on Windows since 0.3.0 beta 7 (E10),
where it keeps Windows' own title bar (`BACKLOG.md` S-56).
Its top is one row, the main window's address row on the page's colour, with the
traffic lights inline and no title bar of macOS's own (E8), light or dark as the main
window is (E9). ⌘O, the row's "Open in Stedding" button, its page menu and the menu bar
move the page into the last-active window, or into a new one when none is open (E7). A
little window has no Space commands. Escape closes it.
A route (routing D1) wins over the little window, and the setting off opens such links as
ordinary tabs.

## Notes

- The little window is Chromium's popup window. Since 2026-10-21 its top is the main
  window's address row with the traffic lights inline (E8); E1's Pin is not built. Its
  size is 1000 × 700 at most, centred over the window that would have taken the link.
- Seen on the real build, not yet explained (BACKLOG S-157): with every normal window
  closed, a link from another app opened as a tab of a new window that brought back the
  closed window's tab, not as a little window (one run, 2026-10-21); and a quit with a
  normal and a little window open hung past the ten-second shutdown watchdog (seen once
  that day; how often is not measured).
- "Open in Stedding" names the browser from its product name (`IDS_PRODUCT_NAME`); the
  button, the page menu and the File menu share one string, and ⌘O is Open File's chord,
  which the little window turns into the move (E2), so the three cannot disagree.
- "Last-active window" is the last activated normal window; with the registry (ADR 0016)
  every normal window shares the Spaces, so the choice only decides where the tab lands.
- VoiceOver: the row is a toolbar with named buttons (Back, Forward, Reload, "Open in
  Stedding"), as the main window's is; not yet heard with a screen reader (critic #31).
