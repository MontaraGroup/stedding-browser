# Stedding 0.3.0 beta 22

A pinned tab's x that removes it, a Copy Link button in little windows, and the number keys your
way. On Chromium 156.0.8078.48.

## New

- **The x on a pinned tab removes it, after asking.** Hover a pinned tab you are not on and click
  its **x**: Stedding asks *Remove this pinned tab?*, and **Remove** unpins and closes it. On the
  pinned tab you are on, the button is a **−** and puts it to sleep, as ⌘W does, keeping it pinned
  (#50).
- **Copy Link in little windows.** A link opened small from another app has the same Copy Link
  button as the main window, with the same "Link copied" confirmation (#48).
- **The number keys, your way.** Settings › Stedding › Shortcuts, under *Jump to Space 1 to 9*:
  Spaces on ⌘1–⌘9 with the rows on ⌃1–⌃9, or either set on ⌃⌘1–⌃⌘9 if macOS uses ⌃1–⌃9 for its
  desktops. On Windows: Ctrl, Alt and Alt+Shift (#13).

## Fixed

- ⌘T (Ctrl+T) on a folder's last tab, when it was also the window's last tab, opened the new tab
  inside the folder. It opens below the folder now (#49, from a contributor).

## Install

- **macOS** (Apple silicon, macOS 13 or later): `Stedding-0.3.0-beta.22-arm64.dmg`, signed and
  notarized. Open it and drag Stedding to Applications.
- **Windows** (10 and 11, x64): `Stedding-0.3.0-beta.22-win-x64.exe`, installs for you alone.
  It is not signed yet: in SmartScreen click **More info**, then **Run anyway**, once.

Installed copies update themselves (Mac from 0.2.0 beta 16, Windows from 0.2.0 beta 19).

## Known limits

- The Windows installer is unsigned (`S-56`).
- Netflix, Disney+ and Spotify's web player do not play yet (`S-270`).
- Chromium 156's built-in list of sites that must load over HTTPS lapses on 13 December 2026;
  a release on a newer base comes before then.

## How it was checked

Every unit and browser test on the Mac (1251 unit and 56 component tests; 610 browser tests,
152 of them one at a time) and on Windows (1246 unit tests; 569 browser tests, 158 of them one
at a time): all passed, except one Windows test that timed out when run beside three others and
passed alone, twice (`S-334`). Each change has a test, and the fix for ⌘T fails its test without
it. On the Mac's release build, by hand: a link from another app opened a little window whose
Copy Link button put the link on the clipboard with its toast; with the Spaces on ⌘, ⌃1 and ⌃2
chose the rows and the Space chip read ⌘1; a pinned tab not on screen asked before it was
removed, Escape kept it and Remove took it.
Apple's distribution check passed the signed app. On Windows the
installer went over an installed beta 21, after an uninstall that kept the profile and on a
clean install, and the installed program is the one the tests ran.
